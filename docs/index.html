Squashage

Graph reconstitution pipeline. Classifies structured JSON records into a deterministic RDF graph; emits Turtle, TriG, N-Triples, N-Quads, or JSON-LD; renders the result as an interactive HTML view.

Live demo

The demo runs entirely in your browser — no server, no data leaves the page. It shows the package's JSON-LD output for a Pathfinder/AONPRD fixture, rendered as a cytoscape graph.

  • Pathfinder (AONPRD) — interactive graph

What it does

Given JSON records like:

{ "_type": "feat", "name": "Power Attack", "level": 1, "rarity": "common",
  "_source": { "target": "aonprd", "url": "https://2e.aonprd.com/Feats.aspx?ID=750" } }

and a config that lists which classifier tasks to apply, Squashage produces a deterministic RDF graph with auto-derived prefixes and an auto-built JSON-LD context. The pipeline:

  • Classifies each record through a deterministic cascade: source contract, structural predicates, JSON-Schema validation, decision-table rules, ontology lookup, conflict resolution.
  • Projects records into RDF/JS quads via user-supplied squash plugins.
  • Quarantines records that don't classify, conflict, or fail validation — graceful, never thrown.
  • Serializes the canonical dataset to a single file, optionally canonicalized via RDFC-1.0.
